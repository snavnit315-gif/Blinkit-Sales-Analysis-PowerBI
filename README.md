# Blinkit-Sales-Analysis-PowerBI
Blinkit Sales Analysis Dashboard built using Microsoft Power BI and Excel# Blinkit Sales Analysis Dashboard | Power BI

## 📊 Project Overview

The Blinkit Sales Analysis Dashboard is an interactive Power BI project created to analyze sales performance, product performance, outlet performance, and customer ratings.

The project uses Microsoft Excel as the source dataset and Microsoft Power BI for data cleaning, transformation, analysis, and visualization.

---

## 🎯 Project Objective

The main objectives of this project are:

- Analyze overall sales performance
- Identify top-performing product categories
- Analyze sales across different outlet types
- Understand product performance
- Analyze customer ratings
- Identify important sales trends
- Create an interactive business dashboard
- Present meaningful business insights through data visualization

## 📂 Dataset

The project uses a Blinkit grocery sales dataset stored in Microsoft Excel.

The dataset contains information related to products, sales, ratings, outlets, outlet types, outlet locations, and other business-related attributes.

### Source Dataset

`Blinkit_Grocery_Data.xlsx`

---

## 🔄 Data Preparation

The dataset was imported into Power BI and prepared using Power Query.

The main data preparation steps included:

- Checking data types
- Handling missing values
- Cleaning inconsistent values
- Transforming columns
- Removing unnecessary data
- Preparing data for analysis
- Creating required fields

---

## 📊 Dashboard Features

### 1. Sales Overview

The overview section provides a high-level summary of business performance using KPI cards and visualizations.

Key metrics include:

- Total Sales
- Number of Items
- Average Sales
- Average Rating

### 2. Product & Sales Analysis

This section focuses on product-level sales performance.

It includes:

- Top Item Types by Sales
- Sales Contribution
- Product Category Analysis
- Fat Content Analysis
- Product Performance

### 3. Outlet Analysis

The dashboard also analyzes sales performance based on outlet characteristics.

The analysis includes:

- Outlet Type
- Outlet Size
- Outlet Location
- Outlet Establishment

---

## 📈 Key KPIs

| KPI | Description |
|---|---|
| Total Sales | Overall sales generated |
| Number of Items | Total number of items |
| Average Sales | Average sales value |
| Average Rating | Average customer rating |

## 💡 Business Insights

The dashboard helps identify:

- Product categories contributing to overall sales
- Differences in sales performance across outlet types
- Product categories with higher sales contribution
